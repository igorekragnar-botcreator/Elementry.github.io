# English Vocabulary Trainer

A simple, offline-friendly web app for practicing English vocabulary from **4000 Essential English Words** (Units 1–15).

## Features

- **15 individual units** — 20 words each
- **Combined quizzes**
  - Units 1–5 (100 words)
  - Units 5–10 (120 words)
  - Units 10–15 (120 words)
- **Word list view** before each quiz
- **Pronunciation** — tap the 🔊 button next to any word (browser speech synthesis)
- **Quiz mode** — see the Russian meaning, type the English word
- Score and progress bar
- Fully client-side — no server, no install

## How to use

1. Open `English_Vocabulary_Trainer_Units_1-15.html` in any modern browser.
2. Choose a single unit or a combined quiz.
3. Review the word list (and listen to pronunciation if needed).
4. Click **Start quiz** / **Начать опрос**.
5. Type the English word for each Russian prompt and check your answer.
